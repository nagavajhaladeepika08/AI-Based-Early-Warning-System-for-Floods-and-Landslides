Notes on These Numbers

Landslide recall/precision (~97-98%) is unusually high for a real-world hazard model — this typically means the source dataset is synthetic/simulated rather than field-collected, since Slope_Angle alone accounts for the vast majority of predictive power. Worth verifying the provenance of wsn_landslide_data.csv before using these numbers in a report.

Flood precision (44.8%) with high recall (86.0%) reflects real class imbalance in the MODIS dataset (only ~4.5% of rows are flooded) — the model is deliberately tuned (class-weighted) to minimize missed floods (false negatives) at the cost of more false alarms, which matches the early-warning priority discussed in the project blueprint. SHAP and XGBoost were not installable in this offline sandbox, so permutation importance replaces SHAP's global explanation here — on your own machine with internet access, swap in shap.TreeExplainer for the real thing.
